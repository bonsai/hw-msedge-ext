# Hello World — Microsoft Edge Extension

Minimal Manifest V3 Hello World extension for Microsoft Edge.

## Files

- `manifest.json` — extension manifest
- `popup.html` — popup UI
- `popup.js` — button interaction

## Local test

1. Open `edge://extensions/`.
2. Enable **Developer mode**.
3. Select **Load unpacked**.
4. Choose this repository directory.
5. Open the extension and click **Click me**.
